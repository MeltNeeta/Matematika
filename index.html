1. Persamaan Lingkaran dengan Pusat O(0,0)

Tahukah kamu bagaimana rumus persamaan lingkaran terbentuk? Yuk, kita temukan rumusnya bersama-sama menggunakan konsep segitiga!

A. Menemukan Konsep

Mari kita bayangkan sebuah lingkaran pada bidang Kartesius yang berpusat di titik O(0,0).

  1. Ambil sembarang titik P(x,y) yang berada di garis lingkaran.
  2. Tarik garis tegak lurus dari titik P ke sumbu X, dan beri nama titik Q. Maka terbentuklah panjang OQ = x dan PQ = y.
  3. Jika kita hubungkan titik pusat O(0,0) ke titik P, garis OP tersebut merupakan jari-jari lingkaran (r).

Sekarang, perhatikan segitiga siku-siku OPQ. Berdasarkan Teorema Pythagoras, kita tahu bahwa:

OP² = OQ² + PQ²

Jika kita substitusikan nilai-nilainya, maka diperoleh:

r² = x² + y²

B. Rumus Utama

📌 Kesimpulan:
Persamaan lingkaran yang berpusat di titik O(0,0) dan memiliki jari-jari r adalah:
x² + y² = r²

C. Mari Mencoba

Soal: Tentukan persamaan lingkaran yang berpusat di O(0,0) dan berjari-jari 3!

Pembahasan: Tinggal masukkan ke rumus:
x² + y² = 3²
x² + y² = 9

Soal: Tentukan persamaan lingkaran yang berpusat di O(0,0) dan melalui titik P(5, 12)!

Pembahasan: Cari r² terlebih dahulu:
r² = 5² + 12²
r² = 25 + 144 = 169
Jadi, persamaannya adalah: x² + y² = 169

2. Persamaan Lingkaran dengan Pusat P(a,b)

Bagaimana jika pusat lingkarannya bergeser dan tidak lagi di titik (0,0)? Jangan khawatir, kita bisa mencarinya menggunakan rumus jarak dua titik!

A. Menemukan Konsep

Misalkan kita memiliki lingkaran dengan titik pusat P(a,b) dan lingkaran tersebut melalui sebuah titik sembarang A(x,y). Jarak dari titik P ke titik A merupakan jari-jari lingkaran (r).

Ingat kembali rumus jarak antara dua titik A(x₁, y₁) dan B(x₂, y₂):

d = √((x₂ - x₁)² + (y₂ - y₁)²)

Jika kita terapkan pada titik pusat P(a,b) dan titik A(x,y), maka jarak AP = r adalah:

r = √((x - a)² + (y - b)²)

Kuadratkan kedua sisi untuk menghilangkan akar:

r² = (x - a)² + (y - b)²

B. Rumus Utama

📌 Kesimpulan:
Persamaan lingkaran yang berpusat di titik P(a,b) dan memiliki jari-jari r adalah:
(x - a)² + (y - b)² = r²

C. Mari Mencoba

Soal: Tentukan persamaan lingkaran dengan pusat P(1,2) dan jari-jari r = 8!

Pembahasan: Substitusi a=1, b=2, dan r=8:
(x - 1)² + (y - 2)² = 8²
(x - 1)² + (y - 2)² = 64

3. Bentuk Umum Persamaan Lingkaran

Jika persamaan pada sub-bab sebelumnya kita jabarkan aljabarnya, kita akan mendapatkan bentuk umum lingkaran yang terlihat lebih panjang.

A. Memahami Rumus

Bentuk umum dari persamaan lingkaran dituliskan sebagai berikut:

x² + y² + Ax + By + C = 0

Jika kamu diberikan persamaan dalam bentuk umum ini, kamu bisa mencari kembali titik pusat dan jari-jarinya menggunakan rumus:

  • Titik Pusat: P = (-½A, -½B)
  • Jari-jari (r): r = √( (-½A)² + (-½B)² - C )

B. Mari Mencoba

Soal: Tentukan pusat dan jari-jari dari lingkaran x² + y² + 4x - 2y + 1 = 0!

Pembahasan:
Diketahui A = 4, B = -2, dan C = 1.

• Pusat = (-½(4), -½(-2)) = (-2, 1)
• Jari-jari r = √((-2)² + (1)² - 1) = √(4 + 1 - 1) = √4 = 2
